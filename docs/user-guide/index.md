# User Guide

This guide describes how to design and build data products on the platform: how events are produced to and
consumed from the shared event backbone, how topics are organized, and how schemas keep producers and
consumers compatible.

Start with the [Design Guide](./design-guide/index.md), which covers:

- [Producers](./design-guide/producers.md): how to publish events to the backbone.
- [Consumers](./design-guide/consumers.md): how to subscribe to and integrate with shared streams.
- [Kafka Topics](./design-guide/kafka-topics.md): how topics are named, partitioned, and retained.
- [Schemas](./design-guide/schemas.md): how event schemas are defined, registered, and evolved.

If you are setting up your machine for the first time, see the
[Development Environment](../contributor-guide/development-environment.md) guide instead.
