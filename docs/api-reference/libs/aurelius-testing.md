# aurelius-testing

This library provides common testing utilities for Aurelius projects.

## Installation

You can include `aurelius-testing` in your project by adding it to your `pyproject.toml`:

```toml
[tool.poetry.groups.dev.dependencies.aurelius-testing]
develop = true
path = "../../libs/aurelius-testing"
```

Ensure the path points to the correct location of the `aurelius-testing` library.
